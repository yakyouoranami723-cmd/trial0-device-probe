# Trial Zero 0.5B Model Probe v0.2.2

## 目的

iPhoneのSafari / ホーム画面PWA上で小型言語モデルを取得・読み込み、WebGPUで日本語回答を生成できるかを段階別に確認する試験です。これはTrial Zero本体ではありません。

## 試験モデル

- `onnx-community/Qwen2.5-0.5B-Instruct`
- ONNX量子化: `q4f16`
- ONNX重みファイル: 約483MB（Tokenizer・設定・ランタイム等は別）
- `@huggingface/transformers` 4.3.2 / WebGPU
- Firebase・外部推論APIは使用しません。初回はjsDelivrからライブラリ、Hugging Faceからモデル関連ファイルを取得します。

## v0.2.2の変更

- 標準設定とConstantFolding無効化の実験設定を選択可能。初期選択は実験設定。
- 読み込み条件と取得できたONNX Runtime Webバージョンを診断ログへ記録。
- 1ページにつきモデル読み込みは1回。失敗後はログを保存し、ページ再読み込み後に別条件を選択。
- モデルキャッシュ識別子は既存の `trial0-transformers-qwen25-05b-v01` を維持。
- Service Workerのシェルキャッシュをv05へ更新。モデルキャッシュとは別管理。
- 入力文と生成結果はログに含めない。

## 実験設定について

実験設定では、Transformers.jsの `session_options` を通して次の設定をONNX Runtimeへ渡します。

```js
{
  extra: {
    'optimization.disable_specified_optimizers': 'ConstantFolding'
  }
}
```

ONNX Runtime公式JavaScript API資料では `extra` はWebAssemblyバックエンド向けと記載されています。一方、Issue #33793では別の共有埋め込みモデルでWebGPU上の効果が報告されています。このため本設定はWebGPUでの正式サポートを保証しない実験です。Qwen2.5-0.5BのONNXグラフは直接解析していないため、同じ原因が発生しているかは未確認です。実験の成功だけで、設定が内部に適用されたと断定しません。

Transformers.js 4.3.2の依存関係は `onnxruntime-web` 1.31.0-dev.20260914-8d85527a0。実行時に取得できたバージョンもログへ記録します。

## iPhoneでの試験順序

1. Wi-Fi接続・十分な充電を確認。
2. 公開ページを一度再読み込みし、v0.2.2の表示になったことを確認。
3. 「モデル設定を確認」を押す。この操作では約483MBの重みをダウンロードしません。
4. 読み込み設定は初期状態の「実験：ConstantFoldingを無効化」のままにする。
5. 確認OKの場合のみ「モデルを読み込む」を1回押す。読み込み中はアプリを閉じず、画面を開いたままにする。
6. 成功表示が出たら `pipeline_create_success` がログにあることを確認。その後に短い日本語プロンプトで生成を1回行う。
7. 白画面・終了・固まり・失敗が発生した場合、連続で再試行しない。ページを再度開き、診断ログをJSON保存して共有する。
8. 別条件を比較する場合は、ログを保存してからページを再読み込みし、「標準：追加設定なし」を選ぶ。1ページ内での再試行はしない。
9. 生成成功後にだけ、別段階としてオフライン再起動試験へ進む。

## 判定基準

- ファイル進捗100%: モデル関連ファイルの取得が終わった可能性を示すが、セッション初期化成功ではない。
- `pipeline_create_start`: pipeline作成開始。
- `pipeline_create_success`: pipeline/モデル読み込み完了。
- `generation_success`: 日本語の生成完了。
- オフライン再起動後の生成成功: さらに別の合格項目。

OSがプロセスを強制終了した場合、終了イベントやエラーがログに残らないことがあります。

## ログとプライバシー

- 記録対象: テスト時刻、ブラウザ環境、セッションID、処理段階、ファイル名、進捗イベント、エラー情報、画面表示状態、読み込み設定、ONNX Runtime Webバージョン。
- 記録しないもの: 入力文、生成した回答。入力文字数・出力文字数は記録します。
- 診断ログは端末のブラウザ内へ保存し、ユーザーがコピーまたはJSON保存した場合のみ外へ持ち出します。
- GitHubの公開リポジトリへ診断JSONをアップロードしないでください。

## 注意

WebGPU APIの存在や小さなGPU計算の成功は、483MB級のLLMが安定して動く保証ではありません。ブラウザのプロセス上限・GPUメモリ・ストレージ永続化の制約があります。iPhoneが高温になる、アプリが終了する、応答しなくなる場合は試験を中止してください。
