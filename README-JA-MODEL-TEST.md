# Trial Zero 0.5B Model Probe v0.2.1

## 目的

iPhoneのSafari / ホーム画面PWA上で小型言語モデルを取得・読み込み、WebGPUで日本語回答を生成できるかを段階別に確認する試験です。これはTrial Zero本体ではありません。

## 試験モデル

- `onnx-community/Qwen2.5-0.5B-Instruct`
- ONNX量子化: `q4f16`
- ONNX重みファイル: 約483MB（Tokenizer・設定・ランタイム等は別）
- `@huggingface/transformers` 4.3.2 / WebGPU
- Firebase・外部推論APIは使用しません。初回はjsDelivrからライブラリ、Hugging Faceからモデル関連ファイルを取得します。

## v0.2.1の変更

- 処理段階とファイル単位の進捗イベントを記録。
- 読み込み失敗時にエラー名・メッセージ・短いスタック情報を記録。
- `pagehide`、`pageshow`、画面の表示状態、未処理エラーも記録し、正常な画面遷移と予期しない終了の切り分けを補助。OSによる強制終了時に終了イベントが必ず残る保証はありません。
- ログは端末のlocalStorageに最大200件保存し、ページ再読み込み後も確認可能。セッションIDと連番を付けて再起動前後のログを区別。
- 診断ログはコピーまたはJSON保存可能。入力文と生成した回答はログへ保存しない。
- モデルキャッシュ識別子は既存v0.1と同じ値を維持。過去の試験で完全に取得済みのモデルファイルを再利用できるようにし、診断コードの更新だけで483MBモデルの再取得を強制しない。
- Service Workerのシェルキャッシュをv04へ更新。モデルキャッシュとは別管理。
- ONNX RuntimeのConstantFolding無効化オプションは採用しない。現行のONNX Runtime JavaScript API資料では `session_options.extra` がWebAssemblyバックエンド限定と記載されているため、WebGPU試験で効く設定として扱えない。過去に検討した仮説は、正確な依存バージョンで対応が確認できるまで保留。

## iPhoneでの試験順序

1. Wi-Fi接続・十分な充電を確認。
2. Safari通常タブで公開ページを開き、まずPhase 0診断を実行。
3. 端末診断結果を保存。次にホーム画面へ追加し、Webアプリとして起動した状態でも同じ診断を行う。
4. モデル試験へ進み、「モデル設定を確認」を押す。この操作では約483MBの重みをダウンロードしない。
5. 確認OKの場合のみ「モデルを読み込む」を押す。初回はアプリを閉じず、読み込みが終わるまで待つ。
6. 読み込み失敗・アプリ終了・固まりが発生した場合、連続で再試行しない。ページを再度開いて診断ログを確認・保存し、原因を切り分ける。
7. 読み込み成功後に短い日本語プロンプトで1回だけ生成。
8. 生成成功後、アプリを完全終了して機内モードで再起動し、再度生成できるか確認する。これはダウンロード・初期化・生成成功とは別の合格項目。

## ログについて

- 記録対象: テスト時刻、ブラウザ環境、セッションID、処理段階、ファイル名、進捗イベント、エラー情報、画面表示状態、キャッシュ件数。
- 記録しないもの: 入力文、生成した回答。入力文字数・出力文字数は記録する。
- ログは端末のブラウザ内へ保存し、ユーザーがコピーまたはJSON保存した場合のみ外へ持ち出す。
- GitHubの公開リポジトリへ診断JSONをアップロードしない。ChatGPT等へ共有する場合、個人情報が含まれていないことを確認。

## キャッシュ

- モデルキャッシュ: `trial0-transformers-qwen25-05b-v01`（既存の試験と同じ識別子）
- 過去の試験で取得済みのファイルを再利用できるよう、診断コードを更新してもキャッシュ識別子は変更しません。
- キャッシュを消して最初から確認したい場合だけ、ページ内の「この試験のモデルキャッシュを削除」を実行してください。対象は上記のモデルキャッシュのみで、診断ページのシェルキャッシュや他サイトのデータは削除しません。削除するとモデルを再取得する可能性があります。

## 注意

WebGPU APIの存在や小さなGPU計算の成功は、483MB級のLLMが安定して動く保証ではありません。ブラウザのプロセス上限・GPUメモリ・ストレージ永続化の制約があります。モデルの読み込み成功、日本語生成成功、再起動後のオフライン生成成功をそれぞれ別に記録してください。端末の正確なRAM容量は、ブラウザから取得できない場合があります。
